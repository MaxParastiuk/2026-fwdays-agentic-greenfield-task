# Icon

The brand's functional line-icon set — Lucide geometry, 24×24, 2px round stroke, inherits `currentColor`. Use for affordances only (upload, copy, status), never decoration or emoji.

```jsx
<Icon name="upload" size={20} />
<Icon name="check" size={16} style={{ color: 'var(--pass)' }} />
```

Names: `upload`, `file-text`, `link`, `globe`, `check`, `copy`, `clipboard-check`, `alert-triangle`, `refresh-cw`, `chevron-down`, `chevron-right`, `x`, `shield`, `arrow-right`, `pen-line` (Maker), `search-check` (Checker), `loader` (spin it with CSS). `ICON_NAMES` exports the full list.
